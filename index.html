📄 Cargar inventario (Excel)

El inventario no se guarda al recargar la página, pero las partidas que añadas a la lista de revisión sí se conservan. El área se toma del nombre de cada hoja y se puede corregir al revisar la partida.

📋 ¿Cómo debe ser el archivo?

Cada hoja del Excel debe tener una fila de encabezados con al menos estas columnas (no importan mayúsculas/minúsculas ni el orden; DIMENSION y NP son opcionales):

CODIGO AX DESCRIPCION DIMENSION NP CANTIDAD
1739 BANDA 3VX900 1
1063 EMPAQUE FLEXITALIC 8" 17

El nombre de la hoja (ej. «CONTENEDOR #1 CONSUMIBLE») se usa como área de sus partidas.

Listas de códigos AX

Archivos CSV o Excel con los códigos y sus nombres, para autocompletar el Nombre al escribir un código. Puedes cargar varias listas a la vez (por ejemplo inventariables y consumibles): cada una toma el nombre de su archivo y luego eliges cuál usar desde el formulario de alta. Volver a cargar un archivo con el mismo nombre actualiza esa lista.

📋 ¿Cómo debe ser el archivo?

La primera fila debe tener los encabezados Codigo AX y Nombre (no importan mayúsculas/minúsculas). Sirve un .csv o un Excel .xlsx:

Codigo AX Nombre
1739 BANDA
1720 ANILLOS
1763 BOMBA HID DE TRANSFERENCIA
